Intha folder-la MongoDB Java driver jar files download panni podanum.
(This folder needs the MongoDB Java driver jars before you compile.)

Download these 3 jars (click each link, it downloads directly) and place
them inside this "lib" folder:

1. https://repo1.maven.org/maven2/org/mongodb/mongodb-driver-sync/5.9.2/mongodb-driver-sync-5.9.2.jar
2. https://repo1.maven.org/maven2/org/mongodb/mongodb-driver-core/5.9.2/mongodb-driver-core-5.9.2.jar
3. https://repo1.maven.org/maven2/org/mongodb/bson/5.9.2/bson-5.9.2.jar

After downloading, this folder should look like:
lib/
  mongodb-driver-sync-5.9.2.jar
  mongodb-driver-core-5.9.2.jar
  bson-5.9.2.jar

Then follow the compile/run steps in the main README.md.
